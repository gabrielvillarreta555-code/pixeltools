## Mira la edición antes que el dispositivo

Decir «juego en PC» no basta: en Windows puede haber más de una edición instalada. Confirma cuál se está abriendo en el lanzador. La documentación oficial distingue dos grupos de juego cruzado.

| Dispositivo o edición | Con quién comparte multijugador nativo |
| --- | --- |
| Android con Bedrock | Otros jugadores de Bedrock compatibles |
| Java en Windows, Mac o Linux | Otros jugadores de Java |
| Bedrock en Windows compatible | Otros jugadores de Bedrock compatibles |

## Qué revisar con tu amigo

Confirmen primero la edición y después las versiones y los permisos de multijugador. Abrir Bedrock en el PC resuelve la diferencia de edición, pero no sustituye los demás requisitos de acceso a una partida.

Si una cuenta tiene controles familiares, el tutor debe revisar los permisos correspondientes. No hace falta falsear la edad ni compartir credenciales para comprobar qué edición está instalada.

## ¿Y los servidores que anuncian Java y Bedrock?

Un servidor puede utilizar soluciones de terceros para conectar clientes distintos. Eso no convierte a las dos ediciones en compatibles de forma nativa ni significa que todas las funciones sean idénticas. Esta guía cubre las opciones oficiales y no recomienda instalar puentes o modificar archivos.

Antes de comprar otra copia, revisa las ediciones que ya tienes disponibles. Una vez en el mismo mundo, [las coordenadas](/juegos/minecraft/activar-coordenadas-bedrock) pueden ayudarte a encontrar a tu amigo.
