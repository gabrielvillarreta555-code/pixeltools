## Una prueba cada vez

Anota cuándo aparece el mensaje. Cambiar muchas cosas a la vez dificulta saber qué ayudó. Esta tabla es una forma de ordenar el diagnóstico, no una identificación automática de la causa.

| Lo que observas | Qué comprobar |
| --- | --- |
| Falla una experiencia, otras abren | Si el problema está limitado a esa experiencia |
| Fallan varias en una sola red | Otra conexión de confianza, si tienes permiso para usarla |
| Falla tras varias sesiones abiertas | Cerrar la app por completo y reiniciar el dispositivo |

## Pasos recomendados

El soporte oficial incluye reiniciar, cerrar Roblox, revisar fecha y hora y probar otra conexión. Empieza por esas acciones reversibles. Una conexión alternativa puede consumir datos; no es necesario pagar una VPN ni instalar un acelerador para hacer la comparación.

Si la aplicación abre pero la imagen va a tirones, la [guía sobre lag](/juegos/roblox/reducir-lag-celular) ayuda a separar gráficos y red.

## Si no cambia nada

Antes de desinstalar, asegúrate de poder recuperar el acceso a tu cuenta. No desactives permanentemente las protecciones del router o teléfono. Si solo falla una red, comparte el diagnóstico con quien la administra; si falla en varias, consulta el soporte de Roblox con el código y el dispositivo.

Evita publicar capturas con correo o información de cuenta. Muestra únicamente el error y oculta los datos personales antes de compartir una captura.
